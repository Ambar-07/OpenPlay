# OpenReceiver

OpenReceiver is a free, open-source AirPlay receiver targeting Android TV / Google TV and Windows. 
The product is deliberately more than a protocol receiver: its differentiator is a premium, cinematic music experience built around the metadata, artwork and playback state exposed by a legitimate AirPlay session.

## Product Thesis
AirPlay is the transport. OpenReceiver is the experience.

## Architecture
- Core: C/C++
- Android TV / Google TV: Kotlin + JNI + Compose TV
- Windows: C# + WinUI 3 + native C++

## Local-first
OpenReceiver is a local-first and hobby-project friendly application. No mandatory cloud backend, database, account, subscription, domain, paid API or hosted infrastructure is required.
